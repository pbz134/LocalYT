Changelog

LocalYT Revamped - Version History

v5.00

  • 50% faster load and search times for all pages by only sending the search index on demand
  • Changed category buttons to not redirect to search.html anymore
    • Instead, results are directly filtered and displayed on index.html
  • Removed playlist_cache.json dependency
    • Playlist thumbnails are now fetched from the first respective playlist-order JSONL entry instead of being hardcoded, this makes it easier to change the current playlist thumbnail
  • Fixed playlist thumbnail encoding where thumbnails wouldn't be displayed when they contained special characters
  • Lowered channel tag influence to 1/3 to prevent recommendation floods
  • Fixed and improved .sidebar-filter-buttons alignment and size
  • Videos in a "Live" subfolder of a channel don't show up on the "Videos" tab anymore (exclusive to "Live" tab)
  • Press the s key when launching the server to skip the incremental scan (in cases where no rescan is needed)
  • Fixed relative upload dates on watch_later.html

v4.90

  • Fully overhauled algorithm
    • Changed from a score-based tag system to a percentage-based tag system
    • Watching one video increases the respective tag(s) by 15% = 15% of your homepage and sidebar content matches these tags
    • Compared to the old system, the new one is able to quickly adapt to user behavior changes
    • Values are not final and may be changed in future updates
    • Feel free to adjust the values at line 1293 and 2664 in server.js
  • Bundled FFmpeg with LocalYT, making it 100% portable
  • Added support for more description chapter formats to LYT Player
  • Fixed thumbnail and .video-description positioning on channel video List view
  • Fixed the video chapter manager permanently focusing on the current chapter
  • Modified createVideoresolutions.py to also get the video codec
    • This helps the LYT Player stats overlay to correctly determine the current video codec
  • Added a way to customize playlist video orders
    • A new script (createPlaylistorders.py) creates .jsonl files that represent all of your channel playlist orders
    • You can modify these .jsonl files to customize the default sorting of playlists
  • Added support for channel.html Discord embeddings
    • Sharing a public LocalYT channel.html link will now display the respective channel name, profile pic and description (if available)
  • Fixed video + metadata special character stripping
    • Due to an issue with how certain special characters in metadata files were handled, many of them were not appearing on videos in LocalYT
    • For anyone having issues with this currently, please execute ".\venv\python.exe LocalYT-Rev-Files\FixMetadataDuplicates.py" to permanently resolve this
    • Make sure to create a backup of your metadata with LocalYT-Debug/backup-files.bat beforehand, just in case!
  • Fixed .video-length size on the video.html Videos tab
  • Moved the Buffer Speed entry below the Buffer entry on Stats for Nerds
  • Fixed Stats for Nerds positioning on full screen vs. windowed video
  • Made the Stats for Nerds overlay movable
  • Added an @ channel handle fallback to comments so that the uploader's profile pic will be shown regardless of the "IsUploader: True" entry
  • New "Not interested" and "Don't recommend channel" button in thumbnail context menu
    • Click the "Not interested button" to reduce the video's respective second tag weight by 50%
    • Click the "Don't recommend channel" to set the video's respective channel tag weight to zero
  • Loading comments now displays a small loading spinner /LocalYT-Rev-Files/Loading-Small.gif
  • Added an entry to settings.html that allows you to customize the amount of videos per row on the channel.html Grid view
  • Fixed account creation rate limit not appearing on register.html
  • Unlocked LYT Player Equalizer for all videos
  • Added three new buttons to the video.html recommendation sidebar to explore more similar content
  • Added tab names in the browser's address bar for settings.html
  • Fixed user's profile pic not showing on the settings.html "Profile Picture" tab
  • Fixed .video-length positioning on index.html
