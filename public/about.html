About LocalYT

LocalYT is a local video library inspired by pre-2020 video platforms.

Overview

It allows you to watch locally-saved videos, integrate metadata into them, and keep track of your watch history.

Algorithm

The algorithm is made possible through video tags, which are generated using LostRuins' koboldcpp API and Alibaba's Qwen2.5 1.5B Instruct model.
