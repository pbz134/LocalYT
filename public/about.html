About LocalYT

LocalYT is a local video library inspired by pre-2020 video platforms

It allows you to watch locally-saved videos, integrate metadata to them, and keep track of your watch history

The algorithm is made possible through video tags, which are generated using LostRuins' koboldcpp API and Alibaba's Qwen2.5 1.5B Instruct model

Coding has been done by DeepSeek-AI's DeepSeek and Z.AI's GLM model series

LocalYT logo made by mitchib1440

Metadata handling is done through Python and Anaconda venvs
