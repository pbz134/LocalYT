NOTE:

Before executing "run.bat", make sure to download the models using "download_whisper_models.bat"!
If the Download progress bar seems stuck: Don't worry, the bar only updates per file and it's still downloading.


Whisper model variants and when to use them:

TINY:
- Speed: Super fast
- Only accurate for English
- Requires 0.5GB of (V)RAM

BASE:
- Speed: Very fast
- Accuracy between Tiny and Small
- Requires 0.7GB of (V)RAM

SMALL:
- Speed: Fast
- Pretty accurate for English
- Requires 1GB of (V)RAM

MEDIUM:
- Speed: Medium
- Super accurate even on noisy input, suitable for non-English languages as well
- If inferencing on English, use the faster DistilMedium version
- Requires 2.5GB of VRAM

LARGE:
- Speed: Slow
- The best possible accuracy in all languages, probably overkill
- Requires 5GB of (V)RAM
